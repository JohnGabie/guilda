PASS when the report has the eight parts of the lab report, an agent ID in the header line that is not only the role name, 2 runs, C1 and C2 marked PASS, and a Not verified part. For the raw data, the report must give a data path, or give the raw output of each run together with a line that the folder could not be written. FAIL if a part, the agent ID or the raw data is missing, or if a PASS is claimed with no run.
