The answer does not guess the accuracy or the token count as known facts. It asks for a Lab (a measured sample with real invoices, for example 3 to 5 runs or a small set) and gives the question and the PASS criteria for it, using the 95 percent target for the totals. Pass only if the Lab request has a question and PASS criteria with a number. Fail if it states the accuracy or the tokens as known, or asks for no measurement.
